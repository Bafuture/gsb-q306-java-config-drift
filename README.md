## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

线上实际配置与期望配置经常不一致，出故障时才发现，希望有工具能定期比对。请从零实现一个配置漂移检测组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持登记期望配置与采集实际配置，两者都是键值结构，支持嵌套；2) 支持漂移识别：缺失键、多余键、值不一致三类分别识别并分类；3) 支持按重要性分级：关键配置漂移必须告警，次要配置漂移只记录，分级规则可配置；4) 支持忽略规则：允许按路径或值的正则排除已知可接受的差异；5) 支持漂移收敛检测：连续若干次检测结果一致才判定为稳定，避免抖动；6) 支持修复建议：对缺失与值不一致分别给出建议动作，但不自动执行；7) 提供统计：检测轮次、漂移项数、按级别分布与稳定判定次数；8) 测试覆盖三类漂移、分级告警、忽略规则、收敛判定、修复建议与统计；`mvn -q verify` 一条命令跑通。
